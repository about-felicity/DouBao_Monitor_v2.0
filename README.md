# DouBao Monitor v2.0

豆包 MuMu 多设备循环提问、网页端同账号抓取、北京时间归档、品牌与竞品分析及本地实时面板。

## 一键部署

1. 安装 Google Chrome、MuMu 模拟器和 Python 3.11 以上版本。
2. 启动需要使用的 MuMu 实例，并在每个实例的豆包 App 中登录账号。
3. 双击根目录的 `一键部署并启动.bat`。
4. 程序会为每个 MuMu 实例建立独立的调试 Chrome。首次运行时，在各 Chrome 中登录对应的豆包账号，然后回到控制面板点击“重新检测账号”。
5. 两端账号匹配后即可开始循环提问。

本地实时面板默认地址：<http://127.0.0.1:8765/>

## API Key

真实密钥仅保存在：

`doubao_mumu_controller/doubao_api_keys.env`

仓库只提供 `doubao_api_keys.env.example`。首次一键部署会自动复制模板；如需未命中品牌词库时调用大模型兜底，请在本机密钥文件中填写自己的 Key。

## 品牌词库

自有品牌和竞品配置保存在 `doubao_brand_settings.json`，会随项目提交。也可以在 MuMu 控制面板的“自有品牌与竞品”页签中维护。

## 多设备规则

- 动态识别当前已启动的 MuMu 实例数量。
- 每个 MuMu 实例对应独立豆包 App 账号、独立 Chrome 用户目录和独立调试端口。
- 所有设备数据写入同一套本地数据文件，可在面板切换单设备或查看全部设备汇总。
- 项目为本机独立模式，不需要把数据上传到另一台电脑。

## 安全说明

GitHub 仓库不应包含真实 API Key、Cookie、Chrome 登录目录、账号令牌或局域网配对令牌。`.gitignore` 已排除这些文件；部署到新电脑后需在该电脑自行登录豆包并配置密钥。
